# ⚙️ Tech Stack & Architecture

## 🎨 Frontend
The frontend was built using:

- **Next.js** → React framework used for building fast and scalable UI.
- **TypeScript** → Added type safety and better code maintainability.
- **Tailwind CSS** → Used for creating a modern and responsive interface.
- **@dnd-kit** → Implemented drag-and-drop functionality for task movement between columns.

---

## 🛠️ Backend
The backend was developed using:

- **Node.js** → Runtime environment for executing backend JavaScript code.
- **Express.js** → Used for creating REST APIs and handling server-side logic.
- **Prisma ORM** → Managed database models, migrations, and queries efficiently.
- **JWT Authentication** → Implemented secure user authentication and protected routes.

---

## 🗄️ Database
- **PostgreSQL / MongoDB** → Used for storing users, boards, and task data.
- Prisma models were used to define:
  - Users
  - Boards
  - Tasks
  - Relationships between entities
